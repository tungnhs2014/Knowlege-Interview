# Agent Instructions

Read and follow `CODEX.md` before working in this project.

For Linux System Programming documentation, prefer the `$linux-system-programming`
skill. The user may provide only Chapter, Topic, and optional Source; use
`LINUX_SYSTEM_LEARNING_MAP.md` to discover mapped TLPI/DevLinux sources and
target output files instead of asking the user for API keywords.

For every write, refactor, or review task, build or verify the Coverage Matrix
from `LINUX_SYSTEM_LEARNING_MAP.md`, mapped sources, current outputs, and the
chapter Must Cover list. Missing coverage is a blocker.

# <NN> - <Topic> Interview Questions

Use this learner-facing template for `interview/NN-<topic>.md`.
Audit metadata belongs in `coverage/topic-briefs/NN-<topic>.md`, not in this file.

Begin with a short intro that explains what strong candidates should be able to reason about.

For each question:

- Level: Beginner / Mid / Senior
- Question
- Short Answer
- Deep Explanation
- API / Code Anchor
- Production or Debugging Angle
- Common Traps
- Follow-up Questions

Coverage rules:

- Beginner questions test mental models and basic lifecycle.
- Mid-level questions test APIs, error paths, userspace interaction, and debugging.
- Senior questions test races, lifetime, ABI design, maintainability, and tradeoffs.
- Include practical debugging scenarios and common traps.
- Use the merged Topic Brief internally, but do not paste source coverage into the interview file.
- Do not accept vague theory-only answers.
